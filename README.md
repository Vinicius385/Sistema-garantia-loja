# 📱 Sistema de Garantia para Assistência Técnica

Sistema desktop desenvolvido em **Python + Tkinter** para gerenciamento de clientes e geração automática de certificados de garantia em PDF para assistências técnicas de celulares.

Ideal para lojas que desejam organizar atendimentos, registrar clientes e emitir garantias profissionais de forma rápida.

---

## 🚀 Funcionalidades

- ✅ Cadastro de clientes
- ✅ Armazenamento em arquivo JSON
- ✅ Geração automática de garantia em PDF
- ✅ Interface moderna feita com Tkinter
- ✅ Controle de número de OS
- ✅ Listagem de clientes cadastrados
- ✅ Exclusão de clientes
- ✅ Layout profissional para impressão

## 📄 Geração de Garantia

O sistema gera automaticamente um PDF contendo:

- Dados do cliente
- Modelo do aparelho
- Serviço realizado
- Valor pago
- Número da OS
- Prazo de garantia
- Condições da garantia

Os arquivos são salvos automaticamente na pasta:

```bash
Garantia Clientes/
```
